# Photos in this project

This project ships with **real photos already included** for the three
heritage sites:

| Filename                       | Used for                                    |
|----------------------------------|------------------------------------------------|
| `hero-hundred-islands.jpg`        | Hero background                               |
| `about-pangasinan.webp`           | About section — provincial coastal view       |
| `bolinao-lighthouse.webp`         | Bolinao Lighthouse                            |
| `balungao-hot-spring.jpg`         | Balungao Hot Spring                           |
| `hundred-islands.jpg`             | Hundred Islands National Park                 |

To swap any of these for a different photo, replace the file (keeping the
same filename) or update the matching path in `src/data/content.js`.

**A note on sourcing photos:**
If you add more photos later, only use ones you have the rights to use:
your own photographs, images explicitly released for reuse (e.g. Wikimedia
Commons photos marked public domain or Creative Commons, with attribution
where required), licensed stock photography, or official photos from the
Pangasinan Provincial Tourism Office or the relevant LGU.

**Tips for best results:**
- Landscape photos (roughly 4:3) work best for Heritage cards and the About photo.
- Wide photos work best for the Hero background.
- Keep files under ~500KB each (export at "web quality," not full camera resolution) so the site stays fast.
